Open this link in the TrueCost app

This email link only works inside TrueCost, on the iPhone where you asked for the email.

  1. On that iPhone, make sure TrueCost is installed.
  2. Go back to the email and tap the link again. If it opens this page, press and hold the link and choose Open in “TrueCost”.
  3. If it still doesn’t open, request a new email from the Profile tab in TrueCost.
